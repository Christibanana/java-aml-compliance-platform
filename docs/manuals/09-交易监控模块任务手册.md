# 交易监控模块任务手册

## 1. 模块目标
安全导入并查询合成交易，为规则执行提供事实。
## 2. 业务背景
交易质量和幂等是监测可信度的基础。
## 3. 功能需求
CSV 导入、校验、去重、错误返回、分页查询。
## 4. 业务流程
选择 CSV→校验表头/逐行字段→查找账户→跳过重复→保存。
## 5. 数据库设计
`aml_transaction`、`aml_transaction_import_batch`；金额 `numeric(19,4)`。
## 6. 后端实现方案
UTF-8 流式读取，`source+external_id` 双重防重。
## 7. 前端页面设计
交易列表、客户/账户筛选、模板下载、上传和批次结果展示已实现。
## 8. API 接口说明
`GET /api/transactions`、`POST /api/transactions/import`、`GET /api/transactions/template`。
## 9. 关键源码路径
`backend/.../transaction`、样例位于 `integrations/amlsim`。
## 10. 权限要求
读取 `CUSTOMER_READ`，导入 `TRANSACTION_IMPORT`。
## 11. 异常处理
空文件、超限、表头、金额、币种、方向、时间、账户错误均拒绝。
## 12. 测试用例
无效表头、复杂引号、合法导入、重复导入与真实 PostgreSQL 关联查询均已通过。
## 13. 验收标准
无效行不落库，重复流水不重复创建，错误可定位行号。
## 14. 已实现功能
查询、批次写入、CSV 引号解析、校验、去重、模板和最多 100 条错误反馈。
## 15. 未实现功能
批次统计列表、异步大文件导入与随机模拟生成器尚未实现。
## 16. 后续扩展建议
改用成熟 CSV 解析器并支持大文件分块与批次重放。

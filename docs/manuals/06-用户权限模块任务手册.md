# 用户权限模块任务手册

## 1. 模块目标
提供安全登录、JWT、RBAC、失败锁定和审计。
## 2. 业务背景
合规数据和处置动作必须按职责隔离。
## 3. 功能需求
登录、五类角色、细粒度权限、BCrypt、失败 5 次锁定 15 分钟。
## 4. 业务流程
提交凭据→校验账户/锁定→签发 JWT→后端权限检查→记录审计。
## 5. 数据库设计
`sys_user/sys_role/sys_permission` 及两个关联表。
## 6. 后端实现方案
Spring Security 无状态过滤链、JJWT、`@PreAuthorize`。
## 7. 前端页面设计
登录页已实现；用户/角色维护页未实现。
## 8. API 接口说明
`POST /api/auth/login`；用户/角色 CRUD 未实现。
## 9. 关键源码路径
`backend/src/main/java/com/example/aml/{auth,security,user}`。
## 10. 权限要求
匿名仅可登录；管理 API 未来要求 `USER_MANAGE`。
## 11. 异常处理
错误凭据统一提示；JWT 无效返回 401，越权返回 403。
## 12. 测试用例
JWT 往返与短密钥拒绝已通过；登录集成与越权接口测试待补。
## 13. 验收标准
密码不明文、令牌有时效、后端权限生效、失败可审计。
## 14. 已实现功能
登录、JWT、BCrypt、角色权限加载、锁定、登录审计、dev 管理员。
## 15. 未实现功能
用户/角色 CRUD、刷新令牌、密码重置。
## 16. 后续扩展建议
增加 MFA、密钥轮换、会话撤销和管理员双人复核。

# 账户管理模块任务手册

## 1. 模块目标
建立账户及客户所有权关系。
## 2. 业务背景
交易必须归属账户并可追溯客户和联名关系。
## 3. 功能需求
账户创建/查询/状态、单客户多账户与联名关系。
## 4. 业务流程
选择客户→录入账号币种与关系→保存账户和关联。
## 5. 数据库设计
`aml_account`、`aml_account_customer`，账号唯一。
## 6. 后端实现方案
JPA 账户实体、复合主键客户关系实体和事务 Service。
## 7. 前端页面设计
账户列表、按客户筛选、新增、状态维护及交易导航已实现。
## 8. API 接口说明
`GET/POST /api/accounts`、`GET /api/accounts/{id}`、`PUT /api/accounts/{id}/status`。
## 9. 关键源码路径
`backend/.../account`、`frontend/src/views/AccountsView.vue`。
## 10. 权限要求
读取 `CUSTOMER_READ`，创建 `ACCOUNT_WRITE`。
## 11. 异常处理
重复账号或客户不存在时拒绝整个事务。
## 12. 测试用例
停用客户禁止开户、关闭账户状态机及真实客户关联 API 已验证。
## 13. 验收标准
账号唯一，关联有类型，可选所有权比例合法。
## 14. 已实现功能
账户创建、详情、按客户查询、客户关系 DTO、冻结/关闭和审计。
## 15. 未实现功能
联名关系追加/编辑与账户状态历史尚未实现。
## 16. 后续扩展建议
增加账户冻结原因和状态历史。

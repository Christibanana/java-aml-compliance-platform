# 风险预警模块任务手册

## 1. 模块目标
承接规则命中并支持可控处置。
## 2. 业务背景
命中只是候选信号，必须由有权限人员审核。
## 3. 功能需求
编号、等级、列表、详情、分派、审核、关闭、升级和历史。
## 4. 业务流程
NEW→ASSIGNED/IN_REVIEW→CLOSED 或 IN_REVIEW→ESCALATED。
## 5. 数据库设计
`aml_alert`、关联交易和历史表。
## 6. 后端实现方案
显式状态转换表，事务内写状态和历史。
## 7. 前端页面设计
列表、开始审核、关闭和升级操作已实现。
## 8. API 接口说明
`/api/alerts` 下详情、assign、transition、escalate。
## 9. 关键源码路径
`backend/.../alert`、`AlertsView.vue`。
## 10. 权限要求
审核 `ALERT_REVIEW`，升级 `CASE_INVESTIGATE`。
## 11. 异常处理
不存在用户/预警或非法状态转换返回业务错误。
## 12. 测试用例
非法 NEW→ESCALATED 已验证拒绝。
## 13. 验收标准
每次转换有历史，关闭/升级后不可继续流转。
## 14. 已实现功能
生成、列表、详情、分派、转换、升级和历史。
## 15. 未实现功能
筛选分页、批量分派、SLA 和通知。
## 16. 后续扩展建议
增加乐观锁冲突处理和工作量均衡分派。

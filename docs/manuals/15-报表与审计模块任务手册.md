# 报表与审计模块任务手册

## 1. 模块目标
提供数据库来源指标、内部报表和不可否认操作轨迹。
## 2. 业务背景
管理与审计需要可复核数据，监管报告不得自动外发。
## 3. 功能需求
预警/客户/规则/案件报表、CSV、审计查询。
## 4. 业务流程
选择范围→数据库聚合→生成内部结果→授权下载/复核。
## 5. 数据库设计
`sys_audit_log`、`aml_report/_generation`。
## 6. 后端实现方案
JdbcTemplate 聚合与同步审计写入。
## 7. 前端页面设计
响应式指标卡、客户风险饼图、预警趋势、规则命中、案件统计、日期筛选、CSV 下载和审计分页筛选已实现；包含加载、空数据、错误重试和无权限状态。
## 8. API 接口说明
`GET /api/dashboard`、`GET /api/reports/{type}/csv`、`GET /api/audit-logs`、`GET /api/audit-logs/export`。
## 9. 关键源码路径
`backend/.../{dashboard,audit}`、对应 Vue 页面。
## 10. 权限要求
看板 `REPORT_READ`，日志 `AUDIT_READ`。
## 11. 异常处理
审计写入失败会使业务事务失败，避免无轨迹写操作。
## 12. 测试用例
HTTP 集成覆盖真实 SQL 聚合、四类统计、业务/审计 CSV、筛选分页及 401/403；PostgreSQL 运行态复验通过。
## 13. 验收标准
指标无硬编码、审计含操作者/动作/资源/时间/结果。
## 14. 已实现功能
七项摘要、风险分布、预警趋势、规则命中、案件状态/优先级、四类业务 CSV、审计筛选分页/CSV和导出审计。
## 15. 未实现功能
异步大报表、哈希签名及正式监管报送草稿/复核流程尚未实现；当前导出上限适合教学数据量。
## 16. 后续扩展建议
加入时间/组织范围、异步生成、哈希签名和保留策略。
